# 38.2o.b — Reptiliano civilizado como híbrido humanoide

## Corrección de enfoque
El modelo ya no debe leerse como un reptil cuadrúpedo ni como un maniquí abstracto, sino como una mezcla de:
- base **humanoide inteligente**, y
- rasgos **reptilianos** evidentes.

## Rasgos reforzados
- postura erguida humanoide,
- cabeza/hocico moderado,
- ojos reptilianos con pupila vertical,
- dientes visibles,
- garras en manos y pies,
- placas/escamas,
- cola secundaria,
- ropa alienígena por nivel civilizatorio.
