# Informe GENESIS 38.bis-T7d

Se corrige el contraste del marcador colonial, se elimina texto redundante del selector superior y se limpia el panel lateral de la inspección colonial.

La inspección ampliada añade una base superficial local alrededor de la colonia para evitar la presentación sobre fondo vacío, y se bloquea el scroll del documento de fondo mientras el modal está abierto.

Validación portable prevista: `node scripts/auditar-genesis-38bis-t7d.spec.cjs`.
