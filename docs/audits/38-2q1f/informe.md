# GENESIS — Auditoría 38.2q1f

## Diversificación morfológica ocular de insectoides civilizados

Se introduce un nuevo módulo procedural de diversidad ocular para insectoides civilizados MUY AVANZADOS.

### Cambios validados

- Se añaden **6 familias oculares** diferenciadas:
  - `ROUNDED_COMPOUND`
  - `OVAL_COMPOUND`
  - `ANGULAR_COMPOUND`
  - `LATERAL_COMPOUND`
  - `PSEUDO_ARACHNOID`
  - `REDUCED_COMPOUND_OCELLI`
- Los **dos ojos compuestos laterales principales** se mantienen como contrato estable.
- Las familias pseudo-aracnoide y de compuestos reducidos añaden **ojos especiales frontales** sin romper el conteo previo de ojos principales.
- Se conserva la **gama negra/obsidiana** heredada de 38.2q1d–38.2q1e.
- El `preview` registra la nueva revisión `VIDA.38.2q1f/ocular-morphological-diversity/v1` en `userData`.

### Validación prevista

- Test Vitest específico `vida38-civilized-insectoid-38-2q1f.spec.ts`.
- Auditor Node `scripts/auditar-genesis-38-2q1f-ocular-diversity.spec.cjs`.
- Revisión visual en galería de civilizaciones, confirmando familias oculares perceptiblemente distintas.
